# Security

Do not disclose vulnerabilities or credentials in a public issue. Use the repository's private vulnerability reporting feature when enabled. If it is unavailable, do not publish exploit details; request a private reporting route without including sensitive information.

Treat initial previews as early software. Set up the owner on a trusted network before exposing a reverse proxy, use HTTPS, limit access and retain independent backups. The default bundle binds the web port to loopback and does not publish PostgreSQL.

No security audit or penetration test is claimed. Automated build checks and home use are not a substitute for one.
