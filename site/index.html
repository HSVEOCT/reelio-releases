BEFORE THE OPENING CREDITS

A few good questions.

Does Reelio include movies or TV shows?

No. Reelio helps you discover and request titles for your own setup. It does not supply media files, download sources or streaming subscriptions. Use services and media you have permission to use.

Is Reelio open source?

No. Reelio is proprietary software, free for personal, non-commercial self-hosting. Official releases contain compiled application files and runtime assembly tools. The application's source code stays private. Third-party components keep their own licences.

Do I need to donate?

No. Donations are entirely optional. They do not unlock features or buy support or source-code access.

Can I use it with my existing server?

The initial release targets Linux amd64 hosts running Docker Compose v2. Jellyfin is the media-server integration, with Radarr and Sonarr optional. Follow the installation guide and keep Reelio in its own directory and Compose project.

How are updates released?

A private build produces a versioned candidate. The maintainer reviews the validated candidate and explicitly approves its public release. Your installation is updated only when you choose to update it.
